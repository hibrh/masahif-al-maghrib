# مصاحف المغرب

دليل مصوَّر للمصاحف المؤرَّخة المعروفة الصاحب في عصور المغرب، من الأدارسة إلى العلويين. لكل عصر صفحة مستقلة.

**الموقع:** https://masahif-al-maghrib.com/

| العصر | الصفحة |
|---|---|
| الأدارسة | https://masahif-al-maghrib.com/adarisa/ |
| المرابطون | https://masahif-al-maghrib.com/murabitun/ |
| الموحدون | https://masahif-al-maghrib.com/muwahhidun/ |
| بنو مرين | https://masahif-al-maghrib.com/marini/ |
| الوطاسيون | https://masahif-al-maghrib.com/wattasi/ |
| السعديون | https://masahif-al-maghrib.com/saadi/ |
| العلويون | https://masahif-al-maghrib.com/alawi/ |

وتُحدَّث الصفحات كلما ظهر مصحف مؤرخ منشور.

## شرط الدليل

تدخل القائمة الأولى في كل عصر المصاحفُ التي اجتمع فيها أمران: تاريخ نسخ صريح في خاتمتها أو وقفيتها، واسم صاحبها، أي ناسخها أو من كُتبت له. ويشترط فيها أيضاً أن تكون قد نُسخت في بلاد تلك الدولة. وفي كل صفحة قسمان آخران: مصاحف ذكرتها المصادر ثم ضاعت، ومصاحف مشهورة تقف على حافة الشرط.

## البنية

- `assets/site.js`: محرك العرض المشترك، وفيه الجدول وخط الزمن والبطاقات وعارض الصور ووضع العرض.
- `assets/site.css`: التصميم المشترك، ولكل عصر لونه.
- `<العصر>/data.js`: بيانات العصر ومصادره.
- `<العصر>/plates/`: العينات المقرَّبة من الكتابة.

## حقوق الصور

أكثر الصور من مكتبات ومتاحف تتيحها ملكاً عاماً أو بترخيص مفتوح. وبعضها منقول بجودة منخفضة من دراسات منشورة، للتعريف بمصاحف لم تُرقمن. ويُذكر مصدر كل صورة تحتها.
